El procesamiento de una muestra sintética en el OPPO funciona con motores locales. El acceso bidireccional al audio de una llamada real, el control de recepción y la integración del asistente en Velo siguen pendientes. La traducción tiene errores de sentido observados; la prueba no estima una precisión general.
